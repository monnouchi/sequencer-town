# シーケンサータウン / Sequencer Town

水路と楽器、木と花壇で曲と街をつくる、monの小さな作品。

[ブラウザで遊ぶ](https://monnouchi.github.io/sequencer-town/)

- 横16マスで2小節、上ほど高い音。泉から水路を引き、水車・雨樋を上下左右につなぎます。鐘・木・花壇・牛・ヤギは水路なしで鳴ります。水路を2×2以上に固めると池になります。
- 水車・雨樋・鐘は同じ段・同じ種類を横につなぐと長い音に。牛・ヤギは一周ごとに空き地を一歩進みます。「移動」「撤去」「水・音の切替」「戻す」で編集できます。建設費・水量の上限やクリア条件はありません。
- 音は操作して開始し、右上でミュート・再試行。メニューで調性、伴奏、昼夜、天気を変更できます。詳しい説明は各道具の「使い方」とメニューの「遊び方」にあります。
- PC・スマホ対応。スマホの道具欄は横へスワイプ、拡大時は「動かす」で移動、「全景」で戻ります。矢印＋Enterで建設、1〜9で道具、Mで音、⌘/Ctrl＋Zで戻す。

街は同じ端末・ブラウザに自動保存されます。メニューからJSONを保存・読み込みでき、保存できない環境ではファイルに保管してください。以前の作曲データも読み込め、さらに古い街は風景・JSON・写真を取り出せます。「街の写真」でPNGを保存し、対応端末では共有先を選べます。

ローカル起動はNode.jsで `npm start` → <http://127.0.0.1:5176>。検証は `npm test` と `npm run check`。依存ライブラリなしの静的アプリで、GitHub Pagesはリポジトリのルートを配信します。
